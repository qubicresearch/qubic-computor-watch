# Qubic Computor Watch

Live, on-chain tracking of Qubic computor-seat concentration — real money-flow
tracing, source-code-verified mechanisms, and live data, not just statistical
correlation.

- Full writeup: https://claude.ai/code/artifact/a7be884a-38bd-4a2c-bbd7-f3028d0b253e
- Single-seat case study: https://claude.ai/code/artifact/e590db27-f2fe-415f-be6d-1685760ca900

Data sourced live, client-side, from rpc.qubic.org, analytics.qubic.li, and
bob.qubic.global. No third-party owner-attribution heuristic is used for the
headline census figures.
