Method & limits

  • Computor set: rpc.qubic.org/v1/epochs/229/computors (676, official).
  • Family/hub resolution: KNOWN dict carried forward, then largest real outgoing transfer ≥100,000,000 QU before tick 80,300,000 (confirmed epoch-230 payout window starts 80,371,514 — this cutoff prevents an address that was also a computor in epoch 230 from having its epoch-229 evidence overwritten by the later, larger epoch-230 payout, which is exactly what happened to the originally-published 229 numbers).
  • This fix used a separate, dedicated cache file for epoch 229 rather than the shared one — going forward, every epoch's classification should use its own cache to prevent this recurring.
  • MinerLab vs JetSki split uses the same brand-naming convention as the epoch-230 report.
  • Every address is checkable at explorer.qubic.org, or below.
