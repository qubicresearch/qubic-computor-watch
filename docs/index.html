The mechanism, in brief

Every candidate identity is auto-funded by pool software (not manually by an operator) the moment it's first used — reproduced directly on independent hardware, four separate times, with zero operator involvement. Each real work submission posts a 1,000,000 QU bond that the network independently re-verifies and only refunds if the recomputed solution matches exactly. Winning a seat isn't a flat contest across all 676: the top 451 ranked identities are copied forward automatically each epoch, while the remaining 225 seats are recomputed after every single valid submission network-wide — a new identity only has to beat the current worst of that 225, not the whole network.
