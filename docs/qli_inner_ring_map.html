VUKEQ's full lifecycle (one address, three roles)

Real, chronological, all on one address: (1) forwarded its own real epoch payouts — 524,333,253 QU and 532,680,571 QU — to ZWLEWECI, same as any other computor. (2) Received the same 10,000,000 QU side-payment documented above, to YHPK (tick 73,881,739). (3) Starting tick 76,572,507, itself fired off dozens of exactly-9,000,000 QU payments to brand-new addresses, one roughly every 35 ticks — the same "Layer 2 secondary funding" mechanism documented in the main write-up's funding-layers table. One address, a full real pipeline: collect payout → forward it → get a small kickback → get reused to onboard the next batch of computors.

All figures, ticks, and addresses above are real and independently verifiable against rpc.qubic.org. This is a zoomed-in supplement to the full network map; see the main write-up for the rest of the investigation. Compiled 2026-09-08.
